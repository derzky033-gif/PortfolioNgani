# 👨‍💻 Derick M. Morales | Personal Portfolio

A modern, responsive, and interactive personal portfolio website showcasing my background, education, technical skills, projects, and professional profile as an Information Technology student and aspiring Front-End Developer.

🌐 **Live Website:** [Visit My Portfolio](https://derzky033-gif.github.io/PortfolioNgani/)

---

## 📌 About the Project

This portfolio serves as my personal digital profile and a central place to showcase my journey in Information Technology, programming experience, technical knowledge, and interests in web development.

It features a modern interface, smooth animations, interactive elements, and responsive layouts to provide a consistent browsing experience across desktop, tablet, and mobile devices.

## ✨ Features

- **Modern User Interface** – Clean, professional, and responsive design.
- **Typing Animation** – Animated introduction and professional titles.
- **Interactive Background** – Floating shapes and animated visual elements.
- **Profile Animation** – Spinning photo ring with technology labels.
- **Scroll Reveal Effects** – Smooth animations while navigating the page.
- **Animated Skill Bars** – Visual representation of technical skills.
- **Language Toggle** – Switch between English and Tagalog.
- **Dark and Light Theme** – Interactive appearance settings.
- **Resume Preview** – View my resume directly on the website.
- **Contact Form** – Prepare an email message through the device's email application.
- **Social Media Integration** – Links to my social media profiles.
- **Responsive Layout** – Optimized for desktop, tablet, and mobile devices.
